## 🔍 SEARCH GUIDE / 搜索指南

To search the knowledge base:
- Use `/kb search [keyword]` or `知识库搜索 [关键词]`
- AI will scan all categories and return matching entries
- Results include source citation and date

To add new content:
- Use `/kb add [content]` or `知识库添加 [内容]`
- Paste documents or paste text directly in chat
- AI will extract, categorize, and index automatically

To update existing entries:
- Use `/kb update [topic] [new content]` or edit this file directly
- Or tell AI: "更新知识库中关于 [主题] 的内容" / "Update KB entry about [topic]"
